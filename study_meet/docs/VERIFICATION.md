# Тексеру нәтижелері

Тексеру күні: 2026 жылғы 21 қазан. Орта: Windows, Flutter 3.47.4 stable, Dart 3.13.3. UI тексерісі жергілікті Flutter Web жинағын Microsoft Edge ішінде іске қосу арқылы орындалды.

## Орындалған тексерулер

- `flutter analyze`: No issues found!
- `dart format --output=none --set-exit-if-changed .`: 15 files, 0 changed, exit code 0.
- `flutter build web --no-web-resources-cdn`: сәтті, build/web жасалды; Wasm dry run да өтті. Қосымша Chromium браузерінде іске қосылды.
- 390 × 844 өлшемінде ашық және қараңғы тақырып көріністері қаралды.
- 1024 × 768 өлшемінде үш бағанды тор қаралды.
- 60 таңбалы атау екі жолда көрсетіледі; карточкаларда шекарадан шығу байқалмады.
- Include past сүзгісі: 10 → 12 → 10 кездесу.
- Профильге ат және CS-2301 тобын енгізіп сақтау.
- Join растауынан кейін Participants саны жаңарып, You белгісі және Leave session батырмасы көрсетілді.
- Leave әрекеті қатысушыны алып тастап, Join батырмасын қайтарады.
- Бос жаңа форманы сақтау атау, орын, күн және уақыт қателерін көрсетеді; форма жабылмайды.
- Өзгертілген формадан Back: Cancel өзгерісті сақтап қалады, Discard негізгі бетке қайтарады.
- Бар кездесудің атауын өңдеп сақтау: бір секундтық сақтаудан кейін detail жаңа атауды көрсетті, Back арқылы негізгі тізімде де жаңа атау табылды.
- Осы орындалған браузер сценарийлерінде JavaScript runtime қатесі тіркелмеді.

## Шектеулер және ескертпелер

- Android APK жиналмаған; Android құрылғысында/эмуляторында тест жүргізілмеген.
- Android predictive back gesture, нақты экран пернетақтасы және экран оқырманы бөлек құрылғылық тексеруді қажет етеді.
- Web build стандартты Flutter құралынан CupertinoIcons туралы ескерту шығарды. Жоба Cupertino белгішелерін тікелей қолданбайды; Material Icons және ашылған экрандар дұрыс көрінді. Бұл анализатор қатесі емес.
- GitHub репозиторийі құрылмаған және push жасалмаған; жергілікті жоба мен Git тарихы берілген.
- Дерек сақтау және желілік API әдейі қосылмаған: тапсырма in-memory модельді талап етеді.
- Қатысушы аты бірегей идентификатор ретінде қаралады; бірдей аттары бар екі адамды ажырату осы модельдің шектеуі.
- Зертхананың талабына сай жоба ішінде автоматтандырылған test/ немесе integration_test/ жинағы жоқ. Жеткізілім алдындағы UI тексеру құралдары жобаға қосылмаған.
